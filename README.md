# Chibishoppu.github.io

Cute one-page landing site for the Chibishoppu GitHub Pages root:
**https://chibishoppu.github.io/**

Links out to:

- [ChibishoppuPOS](https://chibishoppu.github.io/chibishoppu-pos/) — offline-first booth POS
- [Digital Receipt](https://chibishoppu.github.io/chibishoppu-receipt/) — static receipt viewer

## Stack

Plain HTML + CSS. No build step, no dependencies, no JS framework.

## Deployment

This repository is the GitHub **user site** (`Chibishoppu.github.io`) — GitHub
Pages automatically publishes the `main` branch. Push to deploy; no Actions
or Pages configuration needed.

## Files

- `index.html` — hero, about, project cards, footer
- `styles.css` — Chibishoppu brand palette (pink/mint/sky/butter on `#F4F9FE`)
- `ChibishoppuLogo2.jpeg` — shared brand logo
